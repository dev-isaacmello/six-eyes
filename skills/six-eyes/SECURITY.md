# Security Cognition

Analyze:
- auth flow
- token lifecycle
- cookie security
- secret exposure
- SQL injection risks
- SSRF risks
- XSS risks
- permission boundaries
- unsafe MCP usage
- prompt/tool injection paths
- provider adapter privilege boundaries
- generated file writes outside intended workspace

Never allow:
- destructive operations without confirmation
- production database deletion
- secret leakage
- silent execution of provider-specific privileged actions
